# Carta de Cumpleaños

Tarjeta digital con forma de sobre, animaciones de rosas y música.

## Cómo usarla

1. Abre `index.html` en el navegador para probarla.
2. Sube el proyecto a GitHub.
3. Despliégalo en Vercel (gratis) y envíale el link.

## Personalizar

- **Mensaje**: edita el texto dentro de `index.html` (sección `.message`)
- **Nombre en el sobre**: cambia "Mi amor"
- **Firma**: cambia "Tu persona"
- **Música**: coloca un archivo llamado `romantica.mp3` en esta carpeta
